This project demonstrates three Multi-Camera Automotive Targeted Reference Designs (TRDs) targeting the **VEK385 Rev-B1 and B2 Board**. Each TRD showcases different multi-sensor video capture and display capabilities, providing comprehensive examples for high-performance automotive vision processing applications.

The following is a list of Platform Designs available:
| Platform Name  | Description | Links |
| ---------------|------------- | -------------- |
|Multi-Camera Automotive 12×-ISP | The Multi-Camera Automotive 12×-ISP TRD provides high-performance multi-sensor video capture and display capabilities:<ul><li>**12×-ISP Configuration**: 12× MIPI capture (8× 3MP IMX623, 2× 8MP IMX728, 2× 5MP OX05B1S RGB+IR) → ISP processing → DDR → Video Mixer → HDMI-2.1 Tx display pipeline at 8Kp30</li> <li>**Sony 4+1 Configuration**: 5× MIPI capture (4× 3MP IMX623, 1× 8MP IMX728) → ISP processing → DDR → Video Mixer → HDMI-2.1 Tx display pipeline at 4Kp30</li><li>Supports both hardware and software components</li><li>Optimized for scalable multi-camera automotive vision processing</li></ul> | <ul><li>[Documentation](https://xilinx-wiki.atlassian.net/wiki/x/HwCU9w)</li><li>[Prebuilt images](https://account.amd.com/en/forms/downloads/design-license-xef.html?filename=vek385-12x-isp-2026.1-prebuilt-images.zip)</li><li>[Sources and License](https://account.amd.com/en/forms/downloads/design-license-xef.html?filename=vek385-12x-isp-2026.1-sources-licenses.zip)</li></ul>|
|Multi-Camera Automotive 12×8MP | Yet to Publish</li></ul> | |
