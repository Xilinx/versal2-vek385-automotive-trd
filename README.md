This project demonstrates three Multi-Camera Automotive Targeted Reference Designs (TRDs) targeting the VEK385 Rev-B1 board. Each TRD showcases different multi-sensor video capture and display capabilities, providing comprehensive examples for high-performance automotive vision processing applications.

The following is a list of Platform Designs available:
| Platform Name  | Description | Links |
| ---------------|------------- | -------------- |
|Multi-Camera Automotive 12×8MP | The Multi-Camera Automotive 12×8MP TRD provides high-performance multi-sensor video capture and display capabilities: <ul><li>12× MIPI 8MP (IMX728) capture → ISP processing → DDR → Video Mixer → HDMI-2.1 Tx display pipeline at 8Kp30 @ 8bpp</li><li>Supports both hardware and software components</li><li>Optimized for scalable multi-camera automotive vision processing</li></ul> | <ul><li>[Documentation](https://xilinx-wiki.atlassian.net/wiki/x/AQD-4w)</li><li>[Prebuilt images](https://account.amd.com/en/forms/downloads/design-license-xef.html?filename=vek385-hdmi-prebuilt-images.zip)</li><li>[Sources and License](https://account.amd.com/en/forms/downloads/design-license-xef.html?filename=sources-licenses.zip)</li></ul>|
|Multi-Camera Automotive 12×-ISP | The Multi-Camera Automotive 12×-ISP TRD provides high-performance multi-sensor video capture and display capabilities:<ul><li>12× MIPI capture (8× 3MP IMX623, 2× 8MP IMX728, 2× 5MP OX05B1S RGB+IR) → ISP processing → DDR → Video Mixer → HDMI-2.1 Tx display pipeline at 8Kp30 @ 8bpp</li> or  <li>6x MIPI capture (4x 3MP IMX623, 1x 8MP IMX728, 1x 5MP OX05B1S RGB+IR) → ISP processing → DDR → Video Mixer → HDMI-2.1 Tx display pipeline at 8Kp30 @ 8bpp)</li><li>Supports both hardware and software components</li><li>Optimized for scalable multi-camera automotive vision processing</li></ul> | <ul><li>[Documentation](https://xilinx-wiki.atlassian.net/wiki/x/EID64w)</li><li>[Prebuilt images](https://account.amd.com/en/forms/downloads/design-license-xef.html?filename=vek385-hdmi-prebuilt-images.zip)</li><li>[Sources and License](https://account.amd.com/en/forms/downloads/design-license-xef.html?filename=sources-licenses.zip)</li></ul>|
